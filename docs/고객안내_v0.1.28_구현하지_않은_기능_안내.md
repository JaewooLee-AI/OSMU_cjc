**OSMU 워크벤치 v0.1.28**

**구현하지 않은 기능 안내**

씨제이씨협동조합 귀중 · 2026년 10월 23일

# 1. 요약

기능 보완 요청서 v2의 항목 가운데 아래 다섯 가지는 이번 버전에 넣지 않았습니다.
기술적으로 불가능해서가 아니라 대부분 **블로그 계정의 안전**과 **의료법·표시광고법 검수 원칙**을 지키기 위해서이고,
한 가지는 지난 기록에 필요한 정보가 남아 있지 않기 때문입니다.
각 항목마다 이유와, 대신 쓰실 수 있는 방법을 적었습니다.

| # | 구현하지 않은 기능 | 한 줄 이유 | 대신 쓰실 방법 |
|----|------------------|------------------------|------------------------|
| 1 | 앱(PC)이 꺼져 있을 때 자동 작성 | 이 앱은 서버 없이 PC 안에서만 돕니다 | 앱을 켜 두거나, 켤 때 밀린 예약이 자동 작성됩니다 |
| 2 | 자동 발행 | 네이버 계정 제재 위험, 검수 결과는 사람이 확인해야 함 | [지금 게시]가 본문·사진·서식을 넣어 주고 [발행]만 직접 |
| 3 | 업데이트 전 기록의 글별 비용 · 캐시 토큰 구분 | 지난 기록에 그 정보가 없음 | 업데이트 후 기록부터 정확 |
| 4 | 네이버 인용구·구분선 **모양** 자동 선택 | 에디터 버튼 자동 클릭이 필요 → 계정 위험·자주 고장 | 에디터에서 인용구를 한 번 눌러 모양 선택 |
| 5 | [서식 적용]으로 **새 소제목 문장** 만들기 | 검수받지 않은 문장이 본문에 생김 | 소제목이 필요하면 서식을 켜고 [초안 다시 생성] |

# 2. 항목별 설명

## 1) 앱(PC)이 꺼져 있을 때 자동 작성

**요청하신 것**: 정해 둔 시각이 되면 원고를 자동으로 작성.

**지금 동작**: 앱이 켜져 있으면 1분마다 확인해서 예약 시각이 지난 글의 초안을 만듭니다.
앱이 꺼져 있던 동안 지난 예약은 **다음에 앱을 켤 때** 바로 만듭니다.

**꺼져 있을 때 안 되는 이유**: OSMU 워크벤치는 인터넷 서버 없이 사무실 PC 안에서만 도는 프로그램입니다.
글·사진·API 키가 PC 밖으로 나가지 않는 대신, PC나 앱이 꺼져 있으면 일을 해 줄 주체가 없습니다.
Windows 예약 작업으로 앱을 몰래 띄우는 방법도 있지만, 관리자 권한·API 키 보관·화면 없는 실행 문제로 오류가 나도
아무도 모르게 되는 위험이 커서 넣지 않았습니다.

**대신 이렇게 쓰세요**
- 예약해 둔 날에는 앱을 켜 두세요(창을 내려 두어도 됩니다).
- 아침에 앱을 켜면 밤사이 지난 예약이 먼저 처리됩니다.
- 사진이 필요한 글은 예약 전에 사진을 미리 올려 두세요.

## 2) 자동 발행

**요청하신 것**: 예약한 글을 정해진 시각에 네이버에 자동으로 발행.

**지금 동작**: 자동 작성은 '초안'까지입니다. [지금 게시]를 누르면 Chrome 창이 열리고 제목·본문·사진·서식이 자동으로 들어가며,
마지막 **[발행] 버튼만 담당자가 직접** 누릅니다.

**자동으로 하지 않는 이유**
- **계정 안전**: 네이버는 프로그램이 글을 올리는 것을 적극적으로 막습니다. 발행까지 자동으로 하면 블로그 계정이 제재받을 위험이 큽니다.
- **검수 확인**: 모든 초안은 의료법 제56조·표시광고법 기준으로 자동 검수되지만, 검수 결과(점수·지적 사항)는 사람이 보고 판단해야 합니다.
  사람 눈을 거치지 않고 발행되면 문제가 되는 표현이 그대로 나갈 수 있습니다.

**대신 이렇게 쓰세요**: 자동 작성된 초안을 워크벤치에서 확인 → [🚀 네이버 게시 대기열로] → [지금 게시] → Chrome 창에서 [발행].
발행하면 글 주소가 자동으로 저장되고 '게시 완료'로 바뀝니다.

## 3) 업데이트 전 기록의 글별 비용 · 캐시 토큰 구분

**요청하신 것**: 글 1건마다 든 비용, 캐시 토큰을 따로 계산.

**지금 동작**: 업데이트한 뒤부터는 모든 AI 호출이 **어느 글의 호출인지**와 **캐시에서 읽은 양**까지 기록되어,
"이 글 생성 비용 약 ○○원"과 캐시 단가 계산이 정확합니다.

**지난 기록이 안 되는 이유**: 이전 버전은 토큰 수만 기록했고, 그 호출이 어느 글의 것인지, 캐시 토큰이 얼마였는지는 남기지 않았습니다.
없는 정보를 나중에 만들어 낼 수는 없습니다.

**대신 이렇게 보세요**
- 지난 기록도 **전체 금액**에는 들어갑니다(단가를 처음 넣을 때 지난 기록을 그 단가로 한 번 채움).
- 지난 기록의 캐시 토큰은 일반 입력 단가로 계산되므로, 실제보다 약간 높게 보일 수 있습니다.

## 4) 네이버 인용구·구분선 모양 자동 선택

**요청하신 것**: 인용구 스타일(따옴표형·선형 등), 구분선 스타일(기본·점선·굵은 선)을 골라서 반영.

**지금 동작**: 인용구와 구분선 **자체는 네이버에 잘 들어갑니다.** 다만 모양은 항상 **네이버 기본 모양**
(인용구는 큰 따옴표형, 구분선은 기본 선)입니다. 워크벤치에서 모양을 바꾸면 앱의 미리보기만 바뀝니다.

**자동으로 하지 않는 이유**: 네이버 에디터에서 인용구 모양을 바꾸는 방법은 "인용구를 누르고 → 위쪽 도구 막대에서 모양 버튼을 누르는 것"뿐입니다.
붙여 넣는 글에 모양 정보를 담아 보낼 방법이 없습니다. 자동으로 하려면 프로그램이 인용구·구분선마다 Chrome 창의 버튼을 찾아 눌러야 하는데,
- 네이버가 에디터 화면을 조금만 바꿔도 버튼을 못 찾아 자주 고장 나고,
- 자동 클릭이 많을수록 프로그램 사용으로 의심받아 계정이 제재받을 위험이 커집니다.

그래서 처음부터 "에디터 버튼은 자동으로 누르지 않는다"는 원칙을 정했고, 이번 서식 기능도 버튼을 누르지 않고 **붙여넣기 한 번**으로 넣는 방식으로 만들었습니다.

**대신 이렇게 쓰세요**: [지금 게시]로 본문이 들어간 뒤, Chrome 창에서 인용구를 한 번 누르고 위쪽 도구 막대에서 원하는 모양을 고르세요. 글당 1~2개라 몇 초면 됩니다.

## 5) [서식 적용]으로 새 소제목 문장 만들기

**요청하신 것**: 이미 만든 글에 [서식 적용]으로 디자인 요소를 추가.

**지금 동작**: [서식 적용]은 **본문 글자를 한 글자도 바꾸지 않고** 굵게·형광·인용구·구분선·핵심 정리 박스·사진 자리를 입힙니다.
소제목은 본문에 **이미 있는 짧은 줄**만 소제목 모양으로 바꿉니다. 그런 줄이 없으면 소제목 없이 나머지 서식만 들어갑니다.

**새 소제목 문장을 만들지 않는 이유**: 모든 초안은 만들 때 금기어 자동 치환과 AI 법무 검토를 거칩니다.
[서식 적용]은 검수가 끝난 글을 꾸미기만 하는 버튼이라 검수를 다시 하지 않습니다.
여기서 AI가 새 문장(예: "탈모 걱정 끝!" 같은 소제목)을 쓰게 하면, **검수받지 않은 문장이 그대로 발행**될 수 있습니다.

**대신 이렇게 쓰세요**
- 소제목까지 새로 넣고 싶으면 서식 강도를 켠 상태로 [🔁 초안 다시 생성]을 누르세요. 소제목도 본문과 함께 검수됩니다.
- 또는 본문 편집창에서 원하는 줄 앞에 `## `를 직접 붙여 [본문 저장]하면 그 줄이 소제목이 됩니다(직접 쓴 문장은 담당자가 확인한 것으로 봅니다).

# 3. 조건이 붙은 기능 (참고)

구현은 했지만 아래 조건이 있습니다.

| 기능 | 조건 |
|------------------|------------------------------------------------|
| [발행] 후 글 주소 자동 저장 | 앱의 [지금 게시]로 연 Chrome 창에서 발행했을 때만. 손으로 올린 글은 주소를 직접 붙여 넣습니다 |
| 자동 작성 예약 | 앱이 켜져 있을 때만(1번 참고). 메모나 뉴스 기사가 있어야 합니다 |
| 캘린더 끌어다 놓기 | 끌기가 불편하면 칩의 📅 버튼으로 날짜를 고를 수 있습니다 |
| 절감 금액 | 절약된 토큰 자체가 추정치라 금액도 추정입니다 |
| AI 사용 금액 전체 | 등록하신 단가와 환율로 계산한 예산 참고용 추정값입니다. 실제 청구는 각 AI 회사 콘솔에서 확인하세요 |

이 가운데 꼭 필요하신 기능이 있으면 말씀해 주세요. 위험과 대안을 함께 검토해 다시 안내드리겠습니다.
