# 2. 업데이트 전에 알아 두실 것

- **원고 서식이 기본으로 켜집니다.** 업데이트하면 브랜드 킷의 서식 강도가 '표준'이 되어, 다음 초안부터 소제목·강조·인용구 등이 들어갑니다.
  예전처럼 문단만 원하시면 🧵 브랜드 킷 → 🎨 원고 서식에서 강도를 '사용 안 함'으로 바꾸세요.
- **AI 사용 금액은 단가를 넣어야 보입니다.** 가격은 자주 바뀌어 미리 넣어 두지 않았습니다. 넣기 전에는 '단가 미등록'으로 보입니다.
- **자동 작성 예약은 앱이 켜져 있을 때만** 동작합니다. 발행은 자동으로 하지 않습니다.
- 기존 글·브랜드 킷·API 키·네이버 로그인은 업데이트 후에도 그대로 남습니다. 그래도 업데이트 전에 `%APPDATA%\OSMU_CJC` 폴더를 다른 곳에 복사해 두시길 권합니다.
