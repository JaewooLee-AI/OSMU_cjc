# 고객 테스트 항목 — 기능 보완 v2 (대시보드 · 캘린더 · AI 비용 · 원고 서식)

> 작성 2026-10-23 · 대상: 요청서 v2의 요청 1~4를 넣은 버전 (브랜치 `feature/v2-requests`)
> 무엇을 했고 무엇이 안 되는지는 [작업계획_기능보완_v2.md](작업계획_기능보완_v2.md)에 정리했습니다.
> 공개 저장소이므로 API 키·실제 글 내용·블로그 주소는 이 문서나 결과 기록표에 적지 않습니다.

## 먼저 알려 드릴 것

- **원고 서식이 기본으로 켜집니다.** 업데이트 뒤 '기본' 킷의 서식 강도는 **표준**(템플릿 기본형)입니다. 다음 [🪄 초안 생성]부터
  소제목·강조·인용구 등이 들어갑니다. 예전처럼 문단만 원하시면 🧵 브랜드 킷 → 🎨 원고 서식 → 강도 '사용 안 함'으로 바꾸세요.
- **AI 비용은 단가를 넣어야 금액으로 보입니다.** 가격은 자주 바뀌어 기본값을 넣지 않았습니다. 넣기 전에는 '단가 미등록'으로 보입니다.
- **자동 작성 예약은 앱이 켜져 있을 때만** 동작합니다. 꺼져 있던 동안 지난 예약은 다음에 앱을 켤 때 만듭니다. 발행은 자동으로 하지 않습니다.
- **네이버 인용구·구분선 모양(따옴표형·선형 등)은 자동으로 고르지 않습니다.** 에디터에서 한 번 눌러 바꿉니다.
- 금액은 예산 참고용 추정값입니다. 실제 청구는 각 AI 회사 콘솔에서 확인하세요.

## 준비

- [ ] 업데이트 전에 `%APPDATA%\OSMU_CJC` 폴더를 통째로 다른 곳에 복사해 둡니다(되돌리기용).
- [ ] 새 버전 설치 후 앱 실행 → 기존 글·브랜드 킷·API 키가 그대로 있는지 확인
- [ ] 시험용으로 써도 되는 네이버 블로그 (발행한 시험 글은 나중에 지우기)
- [ ] 각 AI 회사의 현재 가격(⚙️ 설정 → 📈 사용량의 [공식 가격 보기]로 확인)

## 1. 대시보드 (요청 1)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 1-1 | 📊 대시보드에서 '소재 대기'나 '초안 완료' 칸의 글을 누름 | 워크벤치로 바뀌고 **그 글이 열린 상태** |
| 1-2 | 통계 카드 '초안 완료'를 누름 → 다시 누름 | 처음엔 초안 완료 글만, 다시 누르면 전체 |
| 1-3 | '작업 중'·'게시 완료' 카드도 같은 방식으로 | 그 상태의 글만 보임 |
| 1-4 | 게시 완료 글(주소를 넣은 글)을 누름 | 기본 브라우저에서 그 네이버 글이 열림 |
| 1-5 | 주소가 없는 게시 완료 글을 누름 | 워크벤치에서 그 글이 열림 |

## 2. 네이버 게시 기록 (요청 1·2)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 2-1 | 🚀 네이버 게시 → [지금 게시] → Chrome 창에서 직접 [발행] | 앱 게시 화면에 "발행을 확인했습니다 — 글 주소를 저장…"이 뜨고, 글이 '게시 완료' 탭으로 이동, 주소가 채워져 있음 |
| 2-2 | 다른 글은 손으로 올린 뒤 [✅ 수동으로 완료] 옆 칸에 글 주소를 붙여 넣고 누름 | 게시 완료 탭에 주소와 게시 시각이 보임 |
| 2-3 | 게시 완료 탭에서 주소를 고치고 [저장], 🔗 버튼 | 저장되고 브라우저로 열림. 주소가 아닌 글자를 넣으면 안내가 뜸 |

## 3. 📅 캘린더 (요청 2)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 3-1 | 워크벤치에서 한 글에 **발행 예정일**을 정하고 [일정 저장] (달력 버튼으로도 골라 보기) | 캘린더 그 날짜에 칩이 보임. 날짜가 하루 밀리지 않음 |
| 3-2 | 캘린더 월간 ↔ 주간, ◀ ▶, [오늘], 브랜드 킷 필터 | 화면이 맞게 바뀜 |
| 3-3 | 상태 색 확인 | 소재 대기 회색 · 생성 중 파랑 · 초안 노랑 · 게시 대기 주황 · 게시 완료 초록 · 실패 빨강 |
| 3-4 | 칩을 누름 | 워크벤치에서 그 글이 열림 |
| 3-5 | 칩을 다른 날짜로 **끌어 놓기**, 칩의 📅 버튼으로 날짜 바꾸기 | 예정일이 바뀜 |
| 3-6 | 예정일이 지난(어제 이전) 미게시 글 | 칩에 ⚠️·빨간 테두리, 상단 '지연 N건', 대시보드 빨간 띠 |
| 3-7 | 빈 날짜를 누름 → [이 날짜로 새 글 만들기] | 워크벤치에 예정일이 들어간 새 글 |
| 3-8 | 오른쪽 '쓸 주제'에 주제 추가 → 날짜 칸으로 끌어 놓기 → [글로 만들기] | 메모·킷·모드·예정일이 채워진 글이 워크벤치에 열림 |
| 3-9 | 반복 규칙 '매주 화요일 · 킷 · 모드' 추가 | 앞으로 4주의 화요일에 점선 주제 칩이 생김. 규칙 삭제 시 글로 안 만든 자리도 사라짐 |
| 3-10 | 글로 만든 주제의 글을 삭제(또는 대시보드 콘텐츠 초기화) | 주제는 남고 다시 [글로 만들기] 가능 |

## 4. 자동 작성 예약 (요청 2)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 4-1 | 메모만 적은 글에 [자동 작성 예약] 켜고 2~3분 뒤 시각으로 [일정 저장], 앱을 켜 둠 | 시각이 지나고 1분 안에 "예약한 글의 초안을 자동으로 만들었습니다" 알림, 글이 '초안 완료' |
| 4-2 | 예약을 걸고 **앱을 끈 채** 시각을 넘긴 뒤 다시 켬 | 켠 직후 그 글의 초안이 만들어짐 |
| 4-3 | 메모 없이 예약 | 시각이 지나면 '실패'로 바뀌고 "쓸 재료가 없습니다" 안내 (반복 시도하지 않음) |
| 4-4 | 자동으로 만든 초안 | 네이버에 자동으로 올라가지 않음 (사람이 검수 후 게시) |

## 5. AI 비용 (요청 3)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 5-1 | ⚙️ 설정 → 📈 사용량 → 단가 표에서 쓰는 모델의 입력·출력 단가(100만 토큰당 $) 입력 → [저장] | "지난 기록 N건을 채웠습니다", 오늘·이번 달·전체 금액이 원화와 달러로 보임 |
| 5-2 | 환율을 실제 환율로 고치고 월 예산(원)을 넣어 [환율·예산 저장] | 금액이 새 환율로 다시 보임 |
| 5-3 | 워크벤치에서 초안 생성 | 리포트 위에 "💰 이 글 생성 비용 약 ○○원 (AI 호출 N회)" |
| 5-4 | 벤더·모델별 표, 글 1건당 평균 | 호출 수·입력·캐시·출력 토큰·금액이 보임 |
| 5-5 | 월 예산을 아주 작게(예: 100원) 넣기 | 대시보드·워크벤치에 "예산의 90%(또는 100%)를 넘었습니다" 안내, 생성은 계속 가능 |
| 5-6 | 단가를 바꾼 뒤 지난 금액 | 지난 금액은 그대로, 새 호출부터 새 단가 |
| 5-7 | 단가를 넣지 않은 모델로 호출 | '단가 미등록'으로 따로 표시(0원으로 세지 않음) |

## 6. 🎨 원고 서식 (요청 4)

| # | 할 일 | 통과 기준 |
|---|---|---|
| 6-1 | 🧵 브랜드 킷 → 🎨 원고 서식에서 템플릿(기본형·정보형·후기형)·강도를 바꾸고 [킷 저장] | 저장됨 |
| 6-2 | 워크벤치에서 강도 '표준'으로 초안 생성 | 오른쪽 네이버 미리보기에 소제목·굵게·형광·인용구·구분선·핵심 정리 박스가 보임. 과하지 않은지(문단당 강조 1~2곳) |
| 6-3 | 같은 메모로 강도 '사용 안 함' → 생성 | 예전처럼 문단만 |
| 6-4 | '🎨 서식' 목록에서 하나 지우기, 굵게↔형광, 인용구·구분선 모양 바꾸기 | 미리보기에 바로 반영 |
| 6-5 | 예전에 만든 글에서 [🎨 서식 적용 (재생성 없이)] | 본문 글자는 그대로, 서식만 생김. "서식 적용 비용 약 ○○원" 표시 |
| 6-6 | 본문 편집창에 `**굵게**` 같은 표시를 직접 쓰고 [본문 저장] | 표시는 사라지고 미리보기에 굵게로 보임 |
| 6-7 | 서식이 있는 글을 [✏️ 수정 반영] | 서식이 (바뀌지 않은 문장에는) 그대로 남음 |
| 6-8 | 컴플라이언스 리포트 | 서식과 관계없이 검수 점수·결과가 나옴. 리포트에 "🎨 서식 N개" 줄 |
| 6-9 | 사진 없는 글의 빨간 '📷 사진 자리' 표시 | 미리보기·게시 화면에 보이고, 게시 화면에 "발행 전에 지워야 합니다" 안내 |
