## 1. 요약 (Executive Summary)

고객님께서 제기해 주신 **"브랜드 킷 1개로 글을 생성할 때 서로 다른 사업 분야(가발 판매·관리 vs 창업 교육·OEM) 내용이 섞이는 문제"**를 해결하기 위해 멀티 브랜드 킷 구조와 프롬프트 격리 로직을 전면 보완하고, 지정해 주신 **Claude Sonnet 5.5(글 생성) + Gemini 3.8 Flash(이미지 분석)** 조합으로 실제 End-to-End 생성 테스트를 완료했습니다.

- **사업 분야 간 내용 섞임 0건 달성**:
  - **B2C 킷 (`가발 판매·관리`)**으로 작성한 가발 세척·보관 글에서 창업 교육·수강생 모집·공장 OEM·스마트팩토리 등 B2B 문구 **0건** 확인
  - **B2B 킷 (`창업 교육·B2B`)**으로 작성한 가발 창업 아카데미 모집 글에서 항암가발·샴푸 세척·린스 등 B2C 관리 문구 **0건** 확인
- **멀티 AI 모델 연동 정상 확인**:
  - **이미지 분석 (`gemini-3.8-flash`)**: 사진 1장 실시간 분석 **2.54초**(입력 1,194토큰 / 출력 55토큰), 동일 사진 재사용 시 콘텐츠 해시 캐시 적중(**0.008초, 토큰 비용 0**) 확인
  - **글 생성 및 검수 (`claude-sonnet-5-5`)**: 네이버 블로그 본문(1,900~2,300자), 인스타그램 캡션, X(트위터) 5연속 스레드, 유튜브 쇼츠 6씬 구성안, 네이버 발행 태그, 의료법·표시광고법 컴플라이언스 검수(93점·95점 통과)까지 전 과정 정상 동작 확인

| **4** | **모델명 정규화 및 비전 토큰 한도 안전장치** | 사용자가 `claude-sonnet-5.5`(마침표)로 입력하면 Anthropic API가 404 오류를 반환(`claude-sonnet-5-5` 하이픈 필요)하고, Gemini 기본 모델명이 구버전(`gemini-2.5-flash`)으로 되어 있었음 | • `ai_workers/multi_llm_router.py`, `ai_workers/vision.py`: 기본 모델명을 `claude-sonnet-5-5` / `gemini-3.8-flash`로 업데이트하고, `5.5` → `5-5` **자동 정규화(`normalize_model_name`)** 및 추론 토큰 여유분(`_REASONING_HEADROOM`) 안전장치 반영 |
| **5** | **워크벤치 킷 전환 시 즉시 동기화** | 워크벤치에서 글의 브랜드 킷을 바꿨을 때 상단 콘텐츠 선택 드롭다운의 `[킷 이름]` 배지와 킷별 기본 콘텐츠 모드가 즉시 갱신되지 않았음 | • `flet_app/views/workbench_view.py`: 킷 변경 즉시 상단 선택 목록의 `[킷 이름]` 라벨과 기본 콘텐츠 모드가 실시간 반영되도록 수정 |

## 3. 테스트 방법 (How We Tested)

고객님께서 정의해 주신 실제 운영 환경과 동일하게 API 및 브랜드 킷을 구성하여 **3단계 실증 테스트**를 수행했습니다.

1. **AI 모델 및 API 설정 검증**
   - **글 생성·검수 기본 모델**: Anthropic `Claude Sonnet 5.5` (`claude-sonnet-5-5`, 마침표 입력 시 자동 변환 포함)
   - **이미지 분석 모델**: Google `Gemini 3.8 Flash` (`gemini-3.8-flash`, `절약(economy, 384px)` 프리셋)
   - 두 API 키 모두 AES-256-GCM으로 암호화하여 앱 로컬 DB(`data/osmu.db`)에 등록하고 실시간 연결 테스트 수행
2. **이미지 분석(Vision) 단독 및 캐시 테스트**
   - 매장/교육장 장비 사진(`202609/3a16ac6c27899248.jpg`)을 대상으로 `gemini-3.8-flash` 실시간 호출 및 2차 재호출(캐시 적중) 측정
3. **분야별 멀티 브랜드 킷 연속 생성 및 혼입 검증 (핵심 테스트)**
   - **시나리오 A (B2C — `가발 판매·관리` 킷)**:
     - **담당자 메모**: *"여름철 땀과 피지가 많을 때 인모 맞춤가발과 항암가발 올바른 세척 주기와 통풍 보관법, 자연스러운 앞머리 스타일링 팁 안내"*
     - **검증 포인트**: B2B 키워드(`가발창업`, `창업교육`, `수강생`, `아카데미`, `OEM`, `스마트팩토리`, `투잡`, `소자본`)가 본문이나 제목에 한 줄이라도 섞이는지 확인
   - **시나리오 B (B2B — `창업 교육·B2B` 킷, 시나리오 A 직후 연속 실행)**:
     - **담당자 메모**: *"가발 창업 아카데미 신규 수강생 모집 안내. ATUM 3D 두상 스캐너 10분 측정 실습과 본사 스마트팩토리 OEM 발주 연계 커리큘럼 소개"* + 매장 장비 사진 1장 첨부
     - **검증 포인트**: 직전에 생성된 시나리오 A(B2C 가발 세척 글)의 서론·결론이나 B2C 키워드(`항암가발`, `항암`, `샴푸`, `세척`, `린스`, `두피케어`, `피지`)가 섞이는지 확인
